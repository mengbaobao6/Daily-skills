# 阿里企业邮箱接入与排查

## 一、三条接入路线（选一条）

| 路线 | 可行性 | 说明 |
|---|---|---|
| 阿里邮箱**官方 MCP** | 仅 **AI 尊享版** / 私有化版 | 端点 `https://qiye.aliyun.com/mcp/streamable/`；Token 在邮箱「设置 → MCP 服务」生成，**有效期 30 天**；好处是 HTTP 直连免客户端，但没有附件下载、没有文件夹/删除管理 |
| **钉钉连接器** | 需该邮箱归属当前钉钉账号 | `dws mail *` 命令最全（60+ 条，含附件下载、撤回）。若邮箱不在当前钉钉名下，`mailbox list` 取不到，报 `domain.notFound`，改不动 |
| **IMAP / SMTP 直连** | 标准版也支持 | **推荐**。能读能发、不受版本限制、不依赖钉钉。本技能采用此路线 |

> 查版本：管理员登录管理后台 `qiye.aliyun.com` → **概览**页顶部显示版本类型。「MCP 服务」是版本判定标尺——标准版不支持。

## 二、服务器参数

| 用途 | 服务器地址 | SSL 端口 | 非加密端口 |
|---|---|---|---|
| 收信（推荐） | `imap.qiye.aliyun.com` | **993** | 143 |
| 收信 | `pop.qiye.aliyun.com` | **995** | 110 |
| 发信 | `smtp.qiye.aliyun.com` | **465** | 25 |

**站点区分**（用 `--site` 切换）：中国内地 `qiye.aliyun.com`（默认 `cn`）｜新加坡 `sg.aliyun.com`（`sg`）｜中国香港 `hk.aliyun.com`（`hk`）｜美国 `us.alibabacloud.com`（`us`）｜德国 `de.alibabacloud.com`（`de`）。

判断方法：登录网页版看域名，如 `mail.hk.aliyun.com` 即中国香港站点。

## 三、三个前提条件（缺一不可）

1. 管理员**未限制**该账号使用三方客户端登录
2. 管理员已为该账号**开启 POP3 / IMAP 服务协议**（推荐组合：IMAP + SMTP）
3. 若启用了「三方客户端安全密码」，客户端密码**必须用安全密码**，邮箱登录密码会失效

**关键结论：若企业未启用「三方客户端登录安全管理」，直接使用邮箱登录密码即可，不需要安全密码。**

## 四、找不到「三方客户端安全密码」入口？

入口藏得深，按此路径：

1. 登录网页版 `https://qiye.aliyun.com/`（国产化版 `https://mail.xc.aliyun.com/`）
2. 点页面**右上角「设置」** → 在弹出的小面板里点 **「查看更多设置」**（最容易漏这步）
3. 左侧导航栏 → **账户与安全 → 账户安全**
4. 找到 **「三方客户端登录安全管理」** → 「三方客户端安全密码」右侧开关

- 开关**已开且无法关闭** = 管理员已强制启用，直接点「生成新密码」
- 生成流程：生成新密码 → 获取动态验证码 → 手机短信验证 → 得到 **16 位**密码，**仅显示一次**，务必立即复制保存
- **完全找不到该区域** = 未启用 → 直接用邮箱登录密码

## 五、常见报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示用户名或密码错误 | 用了邮箱登录密码，但组织已强制安全密码 | 生成三方客户端安全密码后改用 |
| 提示用户名或密码错误（且未启用安全密码） | 密码本身错误 / 账号被锁 | 核对密码；联系管理员 |
| `Resource server does not implement OAuth 2.0 Protected Resource Metadata` | 仅见于官方 MCP 路线，命令拼接/引号问题 | Windows 下 token 必须带引号：`--header "Authorization: Bearer <token>"` |
| 勾选 SSL 后连不上 | 端口仍是非加密端口 | SSL 必须配 993 / 995 / 465 |
| 用自定义域名连不上 | 自建 `imap.你的域名` 需自行上传 SSL 证书 | 改用官方地址 `imap.qiye.aliyun.com`（证书已预置） |
| 管理员未放行三方客户端 | 连接被服务端拒绝 | 管理后台 → 安全管理 → 账号安全策略 → 三方客户端登录安全 → 「启用范围」加入该账号 |

## 六、管理员侧开关位置（转达 IT 时用）

| 目标 | 路径 |
|---|---|
| 放行三方客户端登录 | 安全管理 → 账号安全策略 → **三方客户端登录安全** → 设置「启用范围」 |
| 开启邮件协议 | 组织与用户 → 员工账号 → 该账号 → 功能权限 → **客户端配置** → 开启 IMAP + SMTP |
| 强制启用安全密码 | 安全管理 → 账号安全 → **密码策略** → 强制启用安全密码 |

> ⚠️ 开启「强制启用安全密码」后，**已有的三方客户端连接会立即失效**并提示密码错误，需提前通知使用者重新生成密码。

## 七、自检与验证

```bash
python scripts/aliyun-mail-verify.py                  # 完整自检：IMAP 登录 + 最近邮件 + SMTP 鉴权
python scripts/aliyun-mail-verify.py --site sg        # 海外站点
python scripts/aliyun-mail-verify.py --user x@y.com --pass 'xxxx'   # 临时指定凭据
```

脚本会输出 IMAP 登录结果、收件箱总数与最近 N 封邮件、SMTP 鉴权结果，并针对失败给出针对性提示。**测试不会发送任何邮件。**
