# 跨境电商产品营销方案生成器

分析产品链接（1688/Amazon/淘宝/天猫/独立站）→ 自动提取信息 → 输出完整的商业级营销方案。

本 Skill 封装了一套经过多次迭代验证的标准化流程，**无需重复手动调整**。

---

## 工作流程

### 第一步：获取产品信息

1. 接收用户提供的产品链接（1688、阿里国际站、淘宝、天猫、亚马逊、独立站等均可），或产品图片/基础信息。
2. 使用 `WebFetch` 抓取链接页面内容，提取以下字段：
   - 产品标题/名称
   - 主图URL
   - 价格区间
   - SKU规格（颜色、尺寸、款式）
   - 材质
   - 产品参数（尺寸、重量）
   - 产品描述/详情
   - 店铺/品牌信息
   - 月销量（如有）
   - 起批量
   - 跨境属性（是否跨境出口专供、主要销售地区、主要下游平台）
3. 若页面信息不完整，使用 `WebSearch` 搜索同类目竞品数据辅助判断。
4. **重要**：信息不足时做合理推断，并**必须**标注 `【推断】`。
5. **重要**：所有品牌相关内容必须移除，以"无品牌"呈现（此约束始终生效，与文件名无关）。

### 第二步：输出产品基本信息表

输出以下字段的表格：

| 项目 | 内容 |
|------|------|
| 产品名称 | 多个同义词用 `/` 分隔 |
| 产品类目 | 以 `>` 分层，如：健身器材 > 壶铃 |
| 材质 | 产品实际材质 |
| 产品结构 | 结构描述 |
| 规格参数 | 含推断标记 `【推断】` |
| SKU类型 | 建议按容量/颜色/尺寸组合 |
| 供应商价格 | 人民币原价（1688 批发价） |
| 预估产品价格定位 | 如：入门级/经济型/走量款 |

**规则**：不出现任何品牌名称。

**美金阶梯价格**（按 **1 USD = 6.7 CNY** 换算，基于供应商价加利润后 ÷ 汇率，分三档）：

| 采购量 | 单价（USD / pc） | 计算方式 |
|--------|----------------|----------|
| 10-99 pcs（10个起订） | 供应商价 × 1.30 ÷ 6.7 | 原价 +30% 利润 |
| 100-999 pcs | 供应商价 × 1.25 ÷ 6.7 | 100个以上 +25% |
| 1000+ pcs | 供应商价 × 1.20 ÷ 6.7 | 1000以上 +20% |

> 实际生成方案时，将上式替换为计算后的具体美金数字（如 $10.67 / $10.26 / $9.85），**每个档次必须单独成行显示**，禁止合并到表格单元格内用 `<br>` 拼接。

### 第三步：生成阿里巴巴国际站B2B标题（3个）

**要求**：生成 3 个不同的 B2B 标题，每个标题策略不同，轮流覆盖不同的关键词组合。

**三个标题的策略区分**：

| 标题 | 策略重点 | 说明 |
|------|---------|------|
| 标题 1 | 核心产品词优先 | 头部用最精准的产品关键词，突出产品本身 |
| 标题 2 | 使用场景+功能优先 | 头部用使用场景/功能词，强调适配场景 |
| 标题 3 | 材质+交易词优先 | 头部用材质/工艺+尾部加强B2B交易词 |

**输出格式（每个标题独立一行）**：

```
### 标题 1 — [策略说明]

| 项目 | 内容 |
|------|------|
| 英文标题 | [标题内容] |
| 字符数 | [用 Python len() 程序计算后的真实字符数]字符 |
| 中文释义 | [中文翻译] |

### 标题 2 — [策略说明]

| 项目 | 内容 |
|------|------|
| 英文标题 | [标题内容] |
| 字符数 | [用 Python len() 程序计算后的真实字符数]字符 |
| 中文释义 | [中文翻译] |

### 标题 3 — [策略说明]

| 项目 | 内容 |
|------|------|
| 英文标题 | [标题内容] |
| 字符数 | [用 Python len() 程序计算后的真实字符数]字符 |
| 中文释义 | [中文翻译] |
```

**标题规则（严格遵循，3个标题均适用）**：

- ✅ 长度（含空格）≤ 128字符（阿里国际站标题硬上限）；**建议控制在 110 字符以内**为优
- ✅ 不带逗号（逗号→空格）
- ✅ B2B风格，含批发/工厂/供应商等交易词
- ✅ 头部放核心产品词
- ✅ 尾部放B2B交易词（Wholesale/Factory/Bulk等）
- ❌ 不使用感叹号或其他标点符号
- ✅ SEO优化：核心词前置，功能词中置，交易词后置
- ✅ 3个标题之间关键词分布尽量不重叠，覆盖不同搜索意图
- 🔴 **程序级字符数核查（强制，不可省略）**：标题生成后，**必须执行 Python 命令实际计算**字符数，严禁用估算 / 目测 / AI 自报代替。推荐做法（在终端执行，托管 Python 路径 `C:\Users\UserComputer\.workbuddy\binaries\python\versions\3.13.12\python.exe`）：
  ```bash
  python -c "print(len('在此粘贴英文标题'))"
  ```
  - 将真实字符数填入每个标题的"字符数"字段（即下方 `| 字符数 | [用 Python len() 程序计算后的真实字符数]字符 |` 的 `[数字]`）。
  - **若真实字符数 > 128（阿里国际站上限）**：必须重新生成该标题，删减冗余词直到 ≤ 128；若仍 > 110 也尽量压缩到 110 以内。
  - **若真实字符数与所填"字符数"字段不一致**：一律以程序计算值为准修正字段，不得保留估算值。
  - 三个标题全部通过程序核查（均 ≤ 128 且字段值与程序一致）后，方可进入第四步。

### 第四步：提炼6条核心卖点

**输出格式**：

```
### 英文卖点

1: [第一条英文卖点，含核心搜索词]

2: [第二条英文卖点，含核心搜索词]

...

### 中文释义

1: [第一条中文翻译]

2: [第二条中文翻译]

...
```

**卖点规则**：

- 每条卖点**必须换行分隔**（中间空一行）
- 每条卖点是一句完整的英文，不含破折号
- 每条卖点**必须包含核心搜索词**（如 Adjustable Water Filled Kettlebell）
- 突出**产品特性 + 用户利益**
- 符合SEO规范
- 覆盖不同角度（建议6个）：材质安全、空间收纳、便携设计、定制服务（OEM/ODM）、防漏设计、训练效果
  - 角度可根据品类微调，但**必须产出 6 条**，以填满亚马逊 Listing 卖点位
  - "定制服务"角度用于兼顾 B2B 买家（OEM/ODM/Logo定制/来样加工）

### 第五步：生成 AI 图像 Prompt（智能选图 + 关键词映射）

本步骤**默认采用按品类智能选图**流程，并**始终与 `b2b-image` 技能兼容**——最终输出必须包含 `### Image 1` ~ `### Image 8` 区块，每块含 `**English Prompt:**`（脚本按序号重命名为 `-1.jpg`～`-8.jpg`）。其中 **Image 1-3 为三张主图**，分别对齐 Step 3 的标题1/2/3 三个策略方向，三张主图必须互不相同。

**Image 1-3 三主图特殊规则（分别对应 Step 3 的标题1/2/3，三张必须互不相同）**：

  - **Image 1（对应标题1 核心产品词优先）**：纯白底 45° 产品聚焦主图，锐利焦点高对比度，仅保留主要产品标题文本覆盖（product title text overlay only），干净最小构图（clean minimal composition），删除所有其他文案/卖点/描述性文字（no bullet points no feature text）——突出产品本身。
  - **Image 2（对应标题2 使用场景+功能优先）**：主图融入真实使用场景与功能演示（如产品在健身房/家庭中被执行其核心功能），欧洲白人模特出镜，产品作为场景主角；允许场景背景，但仍需锐利焦点、仅保留简短功能/场景文案——突出"在哪用、怎么用"。

- ✅ 其他图片（Image 4-8）仍必须含 B2B 风格文案文字

7. ✅ 每张图都必须有文字/文案，不能空文字
8. ✅ **尾部统一追加**（必须，原样追加）：

9. ❌ 不能出现中文文字
10. ❌ 不使用引号包裹文字标签（直接在Prompt里写 Plain Portable 而非 'Portable'）
11. ❌ 固定规格：1:1 比例（Ratio 1:1）
12. ✅ 写实超清（ultra realistic 8K high detail）
13. ✅ **左上角 Logo 安全区**（默认所有图生效，不可省略）：在每张图的 English Prompt 中嵌入安全区描述——画面左上角预留约 12% 宽 × 12% 高区域，保持空白，不得放置任何文字、图标、尺寸线、产品主体或重要元素，仅供后期批量贴 Logo 使用，避免遮挡原图文案。统一追加英文短语：`leave top-left corner approximately 12 percent width by 12 percent height as clear empty logo safe zone no text no icon no dimension line no product subject no important element in this zone`

**中文释义必须同步更新**，与英文 Prompt 完全对应。

- 若 `E:\AI Product\<产品名>\` 子目录不存在则新建
