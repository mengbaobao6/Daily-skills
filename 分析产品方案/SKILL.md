# 跨境电商产品营销方案生成器

分析产品链接（1688/Amazon/淘宝/天猫/独立站）→ 自动提取信息 → 输出完整的商业级营销方案。

本 Skill 封装了一套经过多次迭代验证的标准化流程，**无需重复手动调整**。

---

## 工作流程

### 第一步：获取产品信息

1. 接收用户提供的产品链接（1688、阿里国际站、淘宝、天猫、亚马逊、独立站等均可），或产品图片/基础信息。
2. 使用 `WebFetch` 抓取链接页面内容，提取以下字段：
   - 产品标题/名称
   - 主图URL
   - 价格区间
   - SKU规格（颜色、尺寸、款式）
   - 材质
   - 产品参数（尺寸、重量）
   - 产品描述/详情
   - 店铺/品牌信息
   - 月销量（如有）
   - 起批量
   - 跨境属性（是否跨境出口专供、主要销售地区、主要下游平台）
3. 若页面信息不完整，使用 `WebSearch` 搜索同类目竞品数据辅助判断。
4. **重要**：信息不足时做合理推断，并**必须**标注 `【推断】`。
5. **重要**：所有品牌相关内容必须移除，以"无品牌"呈现（此约束始终生效，与文件名无关）。

### 第二步：输出产品基本信息表

输出以下字段的表格：

| 项目 | 内容 |
|------|------|
| 产品名称 | 多个同义词用 `/` 分隔 |
| 产品类目 | 以 `>` 分层，如：健身器材 > 壶铃 |
| 材质 | 产品实际材质 |
| 产品结构 | 结构描述 |
| 规格参数 | 含推断标记 `【推断】` |
| SKU类型 | 建议按容量/颜色/尺寸组合 |
| 供应商价格 | 人民币原价（1688 批发价） |
| 美金阶梯价格 | 按 **1 USD = 6.7 CNY** 换算，分三档：<br>10-100个 = 供应商价格 × 1.25<br>100-1000个 = 供应商价格 × 1.20<br>1000+个 = 供应商价格 × 1.10 |
| 预估产品价格定位 | 如：入门级/经济型/走量款 |

**规则**：不出现任何品牌名称。

### 第三步：生成阿里巴巴国际站B2B标题（3个）

**要求**：生成 3 个不同的 B2B 标题，每个标题策略不同，轮流覆盖不同的关键词组合。

**三个标题的策略区分**：

| 标题 | 策略重点 | 说明 |
|------|---------|------|
| 标题 1 | 核心产品词优先 | 头部用最精准的产品关键词，突出产品本身 |
| 标题 2 | 使用场景+功能优先 | 头部用使用场景/功能词，强调适配场景 |
| 标题 3 | 材质+交易词优先 | 头部用材质/工艺+尾部加强B2B交易词 |

**输出格式（每个标题独立一行）**：

```
### 标题 1 — [策略说明]

| 项目 | 内容 |
|------|------|
| 英文标题 | [标题内容] |
| 字符数 | [数字]字符 |
| 中文释义 | [中文翻译] |

### 标题 2 — [策略说明]

| 项目 | 内容 |
|------|------|
| 英文标题 | [标题内容] |
| 字符数 | [数字]字符 |
| 中文释义 | [中文翻译] |

### 标题 3 — [策略说明]

| 项目 | 内容 |
|------|------|
| 英文标题 | [标题内容] |
| 字符数 | [数字]字符 |
| 中文释义 | [中文翻译] |
```

**标题规则（严格遵循，3个标题均适用）**：

- ✅ 长度（含空格）≤ 110字符
- ✅ 不带逗号（逗号→空格）
- ✅ B2B风格，含批发/工厂/供应商等交易词
- ✅ 头部放核心产品词
- ✅ 尾部放B2B交易词（Wholesale/Factory/Bulk等）
- ❌ 不使用感叹号或其他标点符号
- ✅ SEO优化：核心词前置，功能词中置，交易词后置
- ✅ 3个标题之间关键词分布尽量不重叠，覆盖不同搜索意图

### 第四步：提炼6条核心卖点

**输出格式**：

```
### 英文卖点

1: [第一条英文卖点，含核心搜索词]

2: [第二条英文卖点，含核心搜索词]

...

### 中文释义

1: [第一条中文翻译]

2: [第二条中文翻译]

...
```

**卖点规则**：

- 每条卖点**必须换行分隔**（中间空一行）
- 每条卖点是一句完整的英文，不含破折号
- 每条卖点**必须包含核心搜索词**（如 Adjustable Water Filled Kettlebell）
- 突出**产品特性 + 用户利益**
- 符合SEO规范
- 覆盖不同角度（建议6个）：材质安全、空间收纳、便携设计、定制服务（OEM/ODM）、防漏设计、训练效果
  - 角度可根据品类微调，但**必须产出 6 条**，以填满亚马逊 Listing 卖点位
  - "定制服务"角度用于兼顾 B2B 买家（OEM/ODM/Logo定制/来样加工）

### 第五步：生成 AI 图像 Prompt（智能选图 + 关键词映射）

本步骤**默认采用按品类智能选图**流程，并**始终与 `b2b-image` 技能兼容**——最终输出必须包含 `### Image 1` ~ `### Image 6` 区块，每块含 `**English Prompt:**`（脚本按序号重命名为 `-1.jpg`～`-6.jpg`）。

#### 5.1 智能选图（默认）

AI 先分析以下 5 项：
1. 产品类别
2. 核心卖点（来自第四步的 6 条）
3. 使用场景
4. 亚马逊竞品视觉风格
5. B2B 采购关注点（认证 / 工厂 / 批量）

随后从 **18 种 Creative Direction** 中挑选最适合本产品的 **6 种**（Image 1 固定为高点击主图，Image 2-6 智能挑选）。

**18 种 Creative Direction**：

1. Pure White Hero（CTR白底主图）
2. Premium Studio（高级棚拍）
3. Luxury Branding（品牌高级感）
4. Lifestyle（生活方式）
5. Home Scene（家庭场景）
6. Gym Scene（健身房场景）
7. Feature Focus（卖点展示）
8. Texture Macro（材质微距）
9. Waterproof / Function Test（功能测试）
10. Comparison（竞品对比）
11. Dimensions（尺寸展示）
12. Bundle Display（套装展示）
13. Exploded View（爆炸结构）
14. Cross Section（剖面材质）
15. Infographic（信息图）
16. Floating CGI（悬浮广告）
17. Premium Poster（品牌海报）
18. B2B Trust（OEM/Factory/Certificate）

**自动组合示例**：
- 瑜伽垫：Pure White Hero / Lifestyle / Texture Macro / Feature Focus / Comparison / B2B Trust
- 壶铃：Pure White Hero / Gym Scene / Texture Macro / Feature Focus / Comparison / B2B Trust
- 水瓶：Pure White Hero / Feature Focus / Texture Macro / Lifestyle / Dimensions / B2B Trust

#### 5.2 输出 6 个图片关键词（选图清单）

选定后**立即**输出下表，明确每张图的方向关键词（这是智能选图的可视化结果，便于用户核对与二次调整）：

| 序号 | 图片关键词 (Creative Direction) | 中文释义 |
|------|------|------|
| Image 1 | Pure White Hero | 白底高点击主图 |
| Image 2 | [智能选定方向] | [中文] |
| Image 3 | [智能选定方向] | [中文] |
| Image 4 | [智能选定方向] | [中文] |
| Image 5 | [智能选定方向] | [中文] |
| Image 6 | [智能选定方向] | [中文] |

> **约定**：Image 1 固定为 **Pure White Hero（白底45°高点击主图）**，保证首图点击率，且确保 `b2b-image` 重命名后的 `-1.jpg` 永远是主图。Image 2-6 由 AI 按品类从其余方向中挑选，避免千篇一律。

#### 5.3 映射输出完整 Prompt

按上表顺序，逐张输出 `### Image N` 区块（N = 1..6），每张结构如下：

```
### Image [编号] — [图片关键词名称]

**English Prompt:**
[详细英文Prompt，遵循下方 12 条规则]

**中文释义：**
[中文翻译]
```

**Image 1 高点击主图特殊规则**：
- ✅ 产品具锐利焦点和高对比度（sharp focus high contrast）
- ✅ 仅保留主要产品标题文本覆盖（product title text overlay only）
- ❌ 删除所有其他文案、卖点文字和描述性文字（no bullet points no feature text）
- ✅ 干净最小构图（clean minimal composition）
- ✅ 其他图片（Image 2-6）仍必须含 B2B 风格文案文字

**Prompt 编写规则（严格遵循，不可遗漏）**：

1. ✅ 产品颜色、材质、外观必须与实物**完全一致**
2. ✅ **嵌入产品的真实规格**（尺寸、重量、材质等，根据实际产品数据填写）
3. ✅ **模特全部采用欧洲白种人**（European white）
   - 仅场景类方向（Lifestyle/Home/Gym 等）使用欧洲白人模特（男女按场景定）
   - 其他图不需要模特，或仅用手部展示即可
4. ✅ **白底干净**（pure white background），仅场景类方向可用室内/室外背景
5. ✅ 亚马逊高转化风格（professional Amazon ... image）
6. ✅ 含 B2B 风格文案文字
7. ✅ 每张图都必须有文字/文案，不能空文字
8. ✅ **尾部统一追加**（必须，原样追加）：
   ```
   All in English Including copywriting Nordic Slavic Ratio 1:1
   ```
9. ❌ 不能出现中文文字
10. ❌ 不使用引号包裹文字标签（直接在Prompt里写 Plain Portable 而非 'Portable'）
11. ❌ 固定规格：1:1 比例（Ratio 1:1）
12. ✅ 写实超清（ultra realistic 8K high detail）

**中文释义必须同步更新**，与英文 Prompt 完全对应。

#### 5.3.1 手动出图复制版（默认附在方案末尾）

为支持用户**绕过 b2b-image 自动出图、直接在 `api.0vo.dev` 网页手动生成**，在方案文件末尾**额外**输出一个集中式的"纯文本复制块"。该块与上方 `### Image N` 区块内容一致，但去掉标题与中文释义，便于整段全选复制。

格式固定为：

```
【手动出图复制版 — 直接粘贴到 api.0vo.dev 的 Prompt 框】
Image 1:
[English Prompt 1，含尾部追加文字 All in English Including copywriting Nordic Slavic Ratio 1:1]

Image 2:
[English Prompt 2，含尾部追加文字]

Image 3:
[English Prompt 3，含尾部追加文字]

Image 4:
[English Prompt 4，含尾部追加文字]

Image 5:
[English Prompt 5，含尾部追加文字]

Image 6:
[English Prompt 6，含尾部追加文字]
```

规则：
- 6 个 Prompt 必须与 5.3 的 `### Image 1-6` 区块**完全一致**（同一份文案，仅去掉 `### Image N` 标题与中文释义）。
- 每个 Prompt 必须保留 5.3 的全部规则（尤其尾部 `All in English Including copywriting Nordic Slavic Ratio 1:1`）。
- 参考图需用户在网页**自行上传**（手动模式无法自动传参；脚本模式才自动传）。
- 此块**不会干扰 b2b-image 脚本**：脚本只正则抓取 `### Image N` 区块，本块不是该格式，会被忽略。
- 用户选择自动出图（b2b-image）时可忽略此块；选择手动时可整段复制。

#### 5.4 标准模板模式（可选回退）

当用户明确要求"用标准6图模板" / "不要智能选图" / "固定6图"时，跳过 5.1-5.2，直接采用固定映射：

| 图片 | 方向 | 类型说明 |
|------|------|---------|
| Image 1 | 高点击主图 | 白底45°产品展示，锐利焦点高对比度，仅保留主要产品标题文本覆盖，删除所有其他文案/卖点/描述性文字，干净最小构图 |
| Image 2 | 核心卖点图 | 展示产品核心卖点 |
| Image 3 | 材质细节图 | 特写产品材质/纹理/面料/表面细节，展示质感与做工 |
| Image 4 | 应用场景图 | 真人模特使用产品的生活方式场景（欧洲白人模特） |
| Image 5 | 尺寸图 | 产品搭配尺寸标注/测量示意图/比例参照，清晰展示规格，同时标注常规尺寸和英寸 |
| Image 6 | 采购信任图 | B2B认证/质量标识/工厂实景/售后承诺等信任背书元素 |

仍须遵守 5.3 的全部规则（含 Image 1 特殊规则与 12 条 Prompt 规则）。

## 迭代优化原则

用户可能会提出以下优化需求，**必须按照本考规执行**：

| 用户反馈 | 应对方针 |
|----------|---------|
| "中文释义没同步" | 必须同时更新英文与中文，不可遗漏 |
| "改文案" | 英文改完立即同步改中文释义 |
| "加规格参数" | 嵌入真实产品规格（尺寸/重量/包装）到相关Prompt |
| "删除品牌" | 所有品牌信息移除（无品牌约束始终生效） |
| "加英文限定" | 追加 `All in English Including copywriting Nordic Slavic Ratio 1:1` |
| "每行换行" | 卖点之间空行分隔 |
| "用标准6图模板" | 跳过 5.1-5.2 智能选图，改用 5.4 固定映射 |
| "换某张图方向" | 在 5.2 选图清单中替换对应 Image 的关键词，并重写该 `### Image N` 的 Prompt |
| "手动出图/不用 b2b-image" | 直接复制方案末尾"手动出图复制版"块，去 api.0vo.dev 网页粘贴（参考图自行上传） |
