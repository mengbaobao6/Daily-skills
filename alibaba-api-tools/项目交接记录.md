## 注意事项

1. 不要把 `AppSecret`、`access_token`、`refresh_token` 发给别人。
2. `access_token` 有有效期，过期后需要用 `refresh_token` 刷新。
3. 目前图片银行查询已经证明：token、签名、API 网关均可用。
4. 图片文件名在 PowerShell 输出里可能出现乱码，但 `fileId` 和 `url` 可用。
5. 发品 XML 里的图片必须使用图片银行返回的 `fileId + url`。

## 下一步建议

优先级建议：

1. 查询指定图片分组，拿到某个产品对应的主图和详情图。
2. 调用类目预测接口 `alibaba.icbu.category.predict`。
3. 调用 `alibaba.icbu.product.schema.render` 获取类目必填属性。
4. 根据产品资料生成 `itemSchema XML`。
5. 调用 `alibaba.icbu.product.schema.add.draft` 创建产品草稿。
